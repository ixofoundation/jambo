# CLAUDE.md

Guidance for AI coding agents working on Jambo.

## Branches

- **`jambo-yoma-v2-dev` is the develop branch.** All work goes there first:
  branch from `origin/jambo-yoma-v2-dev` and open every pull request against
  it. That includes hotfixes.
- `jambo-yoma-v2` is the release branch. It only receives merges from
  `jambo-yoma-v2-dev`. Never open a feature pull request straight to it.
- Never commit, push, merge or deploy unless asked.

## Project docs

- `docs/project-structure.md` for the layout of the code.
- `docs/names.md` for how names, avatars and Matrix profiles are resolved.
